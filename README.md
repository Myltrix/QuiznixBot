# 🔥 QuiznixBot — Telegram-бот для викторин с соревновательным режимом и поддержкой ИИ

**QuiznixBot** — это интерактивный и умный Telegram-бот, написанный на Python.
Он объединяет классическую викторину, соревновательные элементы и ответы от искусственного интеллекта, превращая обучение в захватывающий игровой процесс.

---

## 🚀 Основные возможности

### 🎯 **1. Викторина с разными категориями**

Бот поддерживает множество тематик, например:

* Общие знания
* История
* Наука
* География
* IT, программирование
* Фильмы и аниме
* Спорт
* Музыка
* …и многое другое

Пользователь может выбирать любую категорию и уровень сложности:
**Лёгкий**, **Средний**, **Сложный**.

---

### 🧩 **2. Режим соревнований**

QuiznixBot позволяет не просто отвечать на вопросы, а:

* Соревноваться с друзьями
* Участвовать в рейтинге игроков
* Зарабатывать очки и повышать уровень
* Просматривать таблицу лидеров

Рейтинг обновляется автоматически, и каждый игрок может видеть своё место.

---

### 🤖 **3. Поддержка ИИ**

Бот использует искусственный интеллект, чтобы:

* Объяснять правильные ответы
* Давать подсказки при необходимости
* Генерировать дополнительные вопросы
* Общаться с пользователем в свободной форме (mini-chatGPT)

ИИ делает обучение интересным: бот может подробно объяснить тему, рассказать факты или помочь разобраться в ошибках.

---

### 🏆 **4. Система баллов и достижений**

За каждый правильный ответ игрок получает:

* Очки
* Коэффициент сложности
* Награды и достижения

Можно открывать:

* Значки
* Титулы
* Прогресс-бар уровня

Это превращает обучение в полноценную игру.

---

### 📊 **5. Профиль игрока**

Каждый пользователь имеет:

* ID
* Имя
* Уровень
* Количество очков
* Процент правильных ответов
* Историю прохождения викторин

Профиль можно вызвать отдельной командой.

---

### 📨 **6. Удобные команды Telegram**

Использование бота максимально простое.
Примеры команд:

```
/start - Начать работу с ботом
/help - Помощь и описание возможностей
/quiz - Начать викторину
/ai - Задать вопрос AI-помощнику
/stats - Показать мою статистику
/top - Показать таблицу лидеров
/compare - Сравнить статистику с другими игроками
/profile - Показать мой профиль
/clear - Очистить историю диалога
```

## 🏗️ Техническая структура

### 🔧 Стек технологий:

* **Python 3.10+**
* **aiogram / python-telegram-bot** — для Telegram API
* **SQLite / PostgreSQL** — база данных
* **OpenAI API (или аналог)** — ответы и подсказки от ИИ
* **AsyncIO** — высокая производительность

---

## 🧠 Как работает игра

1. Пользователь выбирает категорию и сложность
2. Бот отправляет вопрос + варианты ответа
3. Пользователь выбирает вариант
4. Бот сразу говорит:

   * Правильно или нет
   * Объяснение (может быть сгенерировано ИИ)
5. Начисляет очки
6. Переход к следующему вопросу
7. После завершения — показывает статистику игрока
